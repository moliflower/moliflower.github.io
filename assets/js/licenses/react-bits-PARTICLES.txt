Retained from the source:
- The complete PARTICLE_FRAGMENT shader (particle shapes, soft edges, glow,
  shimmer, and premultiplied output).
- The seeded random-number generator.
- Instanced camera-facing quad rendering and Euler rotation matrix layout.

Customized for this website:
- A new helical torus distribution replaces the original random 3D cloud.
- A new vertex shader controls perspective, depth tint, radius, and subtle
  coherent torus ripple; a small surrounding dust field is included.
- The React lifecycle is replaced by standalone JavaScript with no runtime
  dependencies, CDN requests, analytics, or additional framework.
- Theme-aware teal ink and mint colors, a 55-degree tilted composition, subtle pointer
  rotation, visible play/pause control, persistent manual pause, 30fps limit,
  1.5 DPR cap, reduced-motion static mode, and visibility/GPU fallbacks.
  Animation runs only while visible and a pause control exists; without
  that control the artwork remains static.
