# Notes

这是你的学习笔记目录。课程里的 checkoff 问题、benchmark 数字、读代码的疑问，都写在这里。

建议的文件：

```
notes/
├── TEMPLATE.md          # 每周/每个 assignment 的模板
├── lec01.md             # Lecture 1 的 checkpoint
├── lab00.md             # Lab 0 的 checkoff
├── lab01.md
├── hw01.md
├── project1.md
└── weekly/
    ├── week01.md
    └── ...
```

## 规则

1. **不要抄答案**。checkoff 是给自己看的，不是给老师看的。
2. **带数字**。不要写“变快了”，写“从 96 transaction 降到 12，8×”。
3. **写“没搞懂”**。每周至少留一个“我还不知道”的问题，下周解决。
4. **可以公开，也可以私有**。如果放到公开仓库，注意不要把课程答案/个人隐私放进去。

## 快速开始

```bash
cp notes/TEMPLATE.md notes/lab00.md
```

然后回答 Lab 0 README 最后的 3 个问题。
